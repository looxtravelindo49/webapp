2. Pasang pertama kali

A. Siapkan tempat penyimpanan di GitHub

  1. Buat akun atau masuk ke github.com.
  2. Buat repositori baru bernama lembang-adventures. Boleh pilih Private. Aktifkan pembuatan README agar cabang main tersedia.
  3. Ekstrak ZIP paket ini. Di GitHub, pilih Add file → Upload files.
  4. Unggah folder content, public, dan scripts, lalu file package.json dan package-lock.json. File-file itu harus langsung berada di halaman utama repositori, bukan di dalam satu folder tambahan.
  5. Pilih Commit changes untuk menyimpan.
Penting untuk pengguna Mac: konfigurasi CMS bernama .pages.yml dapat tersembunyi di Finder. Cara mudah: buka CMS-CONFIG.txt, salin seluruh isinya. Di GitHub pilih Add file → Create new file, beri nama persis .pages.yml, tempel isinya, lalu Commit changes. Pastikan namanya tidak menjadi .pages.yml.txt.

Folder dist adalah hasil jadi. Untuk alur edit otomatis, unggah bahan sumber di atas dan biarkan Cloudflare menghasilkan folder dist. Anda tidak perlu memasang Node.js di komputer untuk mengikuti langkah melalui dashboard ini.

B. Hubungkan editor konten

  1. Buka app.pagescms.org dan masuk memakai akun GitHub pemilik repositori.
  2. Ikuti petunjuk untuk memasang GitHub App Pages CMS. Pilih repositori lembang-adventures.
  3. Buka repositori dan cabang main. Konfigurasi dari file .pages.yml akan membentuk menu editor.
  4. Anda akan melihat Identitas & WhatsApp, Beranda, Aktivitas Lembang, Pilihan Tambahan, dan Artikel & Inspirasi.
  5. Isi nomor WhatsApp aktif pada Identitas & WhatsApp. Gunakan awalan 62 atau 08, lalu simpan. Nomor awal sengaja kosong.

C. Tayangkan melalui Cloudflare Pages

  1. Masuk ke dashboard Cloudflare. Buka Workers & Pages → Create application → Pages → Connect to Git. Jika susunan menu berubah, cari pilihan Pages untuk deployment dari Git.
  2. Hubungkan GitHub, lalu pilih repositori lembang-adventures.
  3. Isi pengaturan berikut.

Klik Save and Deploy. Setelah berhasil, Cloudflare memberi alamat …pages.dev untuk memeriksa website. Nama alamat itu mengikuti project yang benar-benar tersedia di akun Anda.

Pilih koneksi Git untuk pemasangan ini agar perubahan dari editor diterbitkan otomatis. Opsi unggah folder hasil jadi secara manual tersedia untuk skenario lain, tetapi tidak dipakai dalam alur pengeditan paket ini.

3. Hubungkan lembangadventures.com

Langkah ini dilakukan setelah domain dibeli dan dapat Anda kelola. Paket ini menggunakan nama pilihan Anda; pembelian dan status ketersediaannya belum ditangani di sini.

  1. Di akun Cloudflare yang sama, tambahkan domain lembangadventures.com dan pilih paket Free.
  2. Cloudflare akan memberikan nameserver khusus. Salin nilai yang tampil di akun Anda.
  3. Masuk ke tempat membeli domain, buka pengaturan nameserver, lalu masukkan nameserver tersebut. Domain tetap dimiliki dan diperpanjang di tempat Anda membelinya.
  4. Tunggu sampai domain berstatus Active di Cloudflare. Jika domain sudah dipakai untuk email, pastikan record email yang ada ikut dipertahankan sebelum mengganti nameserver.
  5. Buka project Pages → Custom domains → Set up a domain, masukkan lembangadventures.com, lalu ikuti konfirmasinya. Tambahkan domain dari menu project ini; bukan sekadar membuat record DNS sendiri.
  6. Jika ingin alamat www.lembangadventures.com, tambahkan juga sebagai custom domain. Anda dapat mengatur pengalihan www ke alamat utama melalui Cloudflare setelah keduanya aktif.
  7. Periksa halaman melalui https://lembangadventures.com setelah status domain dan sertifikat aktif.

Di editor Identitas & WhatsApp → Alamat website, pastikan nilainya https://lembangadventures.com. Nilai ini dipakai untuk alamat utama halaman dan sitemap.

Setelah Save, tunggu proses deployment Cloudflare berstatus Success, lalu muat ulang website. Perubahan konten mengikuti deployment, bukan muncul seketika ketika Anda masih mengetik.

Untuk foto, gunakan dokumentasi asli dan ukuran yang wajar, misalnya WebP/JPG lebar sekitar 1.600 piksel. Ilustrasi pada paket ini hanya pengisi awal. Harga awal berupa “Minta penawaran” agar Anda dapat mengisi angka beserta syarat yang sudah pasti.

Alamat pendek seperti offroad-cikole menjadi bagian dari URL. Hindari menggantinya setelah dibagikan. Jika perlu mengganti, siapkan pengalihan alamat lama.

Di website, /admin/ menyediakan tautan menuju Pages CMS. Login tetap melalui akun GitHub pemilik; halaman itu tidak membuat akun admin atau kata sandi baru.

5. Cara calon pelanggan berkonsultasi

Pengunjung memilih aktivitas, mencentang transportasi/akomodasi/konsumsi bila diperlukan, lalu mengisi peserta, tanggal, dan catatan. Website menyusun pesan yang bisa diperiksa dan diteruskan ke WhatsApp. Pesan baru dikirim setelah pengunjung melanjutkan proses di WhatsApp.

Isian konsultasi tidak disimpan ke server website dalam versi ini. Harga tambahan tidak dijumlahkan otomatis karena nominal dan ketentuannya perlu mengikuti penawaran.

6. Batas paket gratis

Saat dokumentasi diperiksa, Cloudflare Pages Free menyediakan 500 build per bulan dan maksimum 25 MiB per file aset. Penyimpanan situs gratis dibatasi 20.000 file. Penyimpanan foto dan jumlah pembaruan tetap perlu disesuaikan dengan batas layanan. Website ini memakai aset statis, tanpa database atau Pages Functions.

Pages CMS versi online tersedia gratis. Domain dan perpanjangannya tetap dibayar terpisah. Ketentuan layanan dapat berubah; rujuk halaman resmi saat memasang.

7. Jika ada yang belum bekerja

Editor meminta konfigurasi atau tidak menampilkan menu

Periksa apakah .pages.yml ada di akar repositori pada cabang main. Buka CMS-CONFIG.txt untuk menyalin konfigurasi yang benar. Pastikan Pages CMS terhubung ke repositori yang sama.

Cloudflare menampilkan “package.json not found”

File sumber kemungkinan diunggah di dalam folder pembungkus. Pindahkan package.json, content, public, dan scripts ke akar repositori. Alternatifnya, isikan nama folder tersebut pada Root directory di Cloudflare.

Perubahan tersimpan tetapi website belum berubah

Periksa apakah editor memakai cabang main dan deployment terbaru berhasil. Bila build gagal, versi sebelumnya tetap tampil. Buka pesan build untuk menemukan kolom yang perlu diperbaiki, misalnya nomor WhatsApp atau alamat halaman yang tidak valid.

Tombol WhatsApp belum muncul

Isi nomor aktif di Identitas & WhatsApp, simpan, dan tunggu deployment berhasil. Nomor harus memakai format Indonesia yang benar. Sebelum nomor diisi, situs hanya menyediakan salinan brief.

Foto tidak tampil

Pilih foto melalui kolom gambar di Pages CMS agar tersimpan ke public/media dengan alamat /media. Simpan halaman sesudah memilih gambar. Gunakan JPG, PNG, WebP, AVIF, atau SVG.

Domain belum aktif

Pastikan nameserver sudah sama dengan nilai dari akun Cloudflare, domain sudah Active, dan custom domain sudah ditambahkan pada project Pages yang tepat. Pengaturan dan waktu pemrosesan domain berbeda dari proses build website.

8. Pemeriksaan paket

Build lokal dan lima pengujian otomatis lulus: pembuatan halaman, perubahan konten, penyembunyian draft, penambahan aktivitas, penanganan input, nomor WhatsApp, dan logo. Struktur HTML dan tautan lokal diperiksa secara terpisah. Alur login Pages CMS, koneksi akun Cloudflare, pengiriman WhatsApp, dan tampilan browser nyata perlu diperiksa setelah pemasangan pada akun Anda.

Untuk pemeriksaan teknis lokal tersedia npm test dan npm run build. Pemilik website tidak perlu menjalankan perintah tersebut untuk edit harian melalui CMS.
